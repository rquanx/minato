## 验收条件

- [x] 默认关闭时基础用量可查，Minato 和 LiteLLM 默认日志均无正文。开启后可查看成功、失败及中断样本。
- [x] 正文截断和到期有明确状态。跨环境读取失败，正文清理后调用元数据仍可查。
